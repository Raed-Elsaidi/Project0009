# Supabase
1. أنشئ مشروع Supabase باسم educational-counselor.
2. نفّذ supabase/schema.sql في SQL Editor.
3. انسخ .env.example إلى .env.local.
4. ضع VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY.
5. npm install ثم npm run dev.
6. أنشئ مستخدمًا من Authentication > Users ثم أنشئ profile مرتبطًا به حسب schema.
