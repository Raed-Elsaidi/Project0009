# تحديث إدارة الهيكل والحسابات

## ما تم إضافته
- شاشة **المديريات** لمسؤول الإرشاد فقط: اسم المديرية + كود من رقمين.
- شاشة **المدارس** مستقلة: رئيس القسم يضيف المدرسة داخل مديرته، والكود إلزامي 8 أرقام.
- شاشة **إدارة الموظفين**:
  - مسؤول الإرشاد: إنشاء رؤساء الأقسام والمشرفين والمرشدين.
  - رئيس القسم: إنشاء المشرفين والمرشدين داخل مديريته.
  - اسم المستخدم فريد على مستوى النظام.
  - المشرف يمكن ربطه بقائمة مرشدين حتى 20 مرشدًا.
- شاشة **المراسلات** موجودة ومفعلة ضمن الهيكل، مع صوت عند وصول رسالة جديدة وصوت خفيف عند التنقل.
- شاشة **الملاحظات** موجودة ومصممة للهواتف.
- شاشة **تغيير كلمة المرور** مع زر «نسيت كلمة المرور؟».
- شاشة **نسيت كلمة المرور** ترسل طلبًا لمسؤول الإرشاد، وبعد التحقق ينشئ مسؤول الإرشاد كلمة جديدة ويرسلها من شاشة المراسلات.
- التصميم Responsive للهواتف الصغيرة.

## الأمان
- شروط كلمة المرور: 8–10 محارف، حرف كبير، حرف صغير، رقم، ورمز.
- كلمات المرور لا تُحفظ في جداول التطبيق؛ يتم إنشاء/تحديث الحسابات عبر Supabase Auth، الذي يتولى تخزين الهاش الخاص بكلمة المرور.
- لم يتم إضافة «8 مرات SHA» إلى قاعدة البيانات لأن ذلك يكرر تخزين/تجزئة الاعتماد خارج نظام المصادقة وقد يضعف التصميم الأمني. الرقم 8 هنا مطبق كحد أدنى لطول كلمة المرور كما طلبت، مع بقية شروط التعقيد.
